# AuraNotes AI ✨

AuraNotes AI is a Flask-based AI notes assistant that:

- Uploads PDF notes
- Generates AI summaries
- Creates viva questions
- Creates flashcards
- Downloads study notes as PDF

## Tech Stack
- Python
- Flask
- HTML
- CSS

## Features
- PDF Text Extraction
- AI Summary Modes
- Viva Question Generator
- Flashcards
- Downloadable PDF Notes# AuraNotes-AI
